# Descripcion de datos
En los siguientes directorios se pueden encontrar los datos recolectados de distintas ejecuciones en MVs de Windows10 y Ubuntu 22.04 tanto normales como infectadas de distintos ransomwares. Salvo aquellas ejecuciones en las que ha habido problemas y no se han podido rescatar todos los datos, cada ejecucion consta de:
- Un archivo de datos de uso de HW.
- Un archivo de datos sobre servicios.
- Un archivo de datos sobre procesos.
- Un archivo de datos sobre eventos del sistema.
- Un archivo de datos sobre actividad en el sistema de archivos.
- Un archivo de datos sobre actividad de red (no se usa en los análisis).
También, en cada ejecucion infectada de ransomware, se peude encontrar el sha256 de la muestra utilizada.
